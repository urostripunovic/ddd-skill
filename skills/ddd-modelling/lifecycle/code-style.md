# Code style

1. The choice recorded under `## Domain code` in the agent instructions (`CLAUDE.md` or `AGENTS.md`). An explicit "the repository's own" wins over cards left from an earlier setup.
2. Without a record: installed pattern cards (`docs/ddd/cards/`) mean the kit's functional style; no cards mean the repository's own style.

Never ask the user to choose again. In the repository's own style, the model's rules, names and examples still hold; its typed patterns do not, and their absence is never a finding.
